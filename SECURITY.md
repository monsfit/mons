# Security policy

Security fixes are supported on the latest `main` branch and on the currently deployed Mons
service. Older commits and third-party forks are not maintained releases.

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a
vulnerability** action in the Security tab of this repository and include reproduction steps,
affected versions or endpoints, and the likely impact. Do not include real user data or production
credentials in a report.

For ordinary bugs without security impact, open a regular GitHub issue.
